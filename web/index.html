    遇到的障碍

    “独立完成”是试用者或观察者的判断；操作事件只能佐证按钮与接口响应，不能证明已理解。软件不能核验真人身份。请勿把演练记录改成真实参与者记录。

    导入文件操作计划

    粘贴由 AI 或其他工具生成的操作 JSON。月盾会独立验证路径、冲突和内容。

    支持 create、write、move、trash。仅处理工作区内受支持的文本文件。

    打开本地资料目录

    粘贴文件夹的完整路径。首次使用建议选择资料副本；文件内容会显示在本地工作台。

    可在文件管理器的地址栏复制路径。切换会清除当前未执行计划；恢复日志仍保存在各自目录。执行和恢复期间，请暂停其他应用对这个目录的写入。

    创建文件操作计划

    把需要的操作加入列表，再统一预演。这里不会直接修改文件。

    使用 / 分隔子目录。移动不自动修改文档链接；回收可从月盾恢复记录还原。

      从资料目录到可恢复的变更

      1. 打开目录

        点击「打开资料目录」，粘贴完整文件夹路径。默认的示例可用于熟悉流程。

      2. 创建计划

        点击「新建操作」移动、重命名、新建、修改或回收文件。也可导入外部工具生成的 JSON。

      3. 检查后执行

        逐个查看文件变化，点击「确认并执行」。如果资料在预演后被修改，请重新预演。

      4. 检查并恢复

        在「恢复记录」中选择操作。后续人工修改发生冲突时，月盾会停止覆盖。

      “按主题归档”读取根目录 Markdown 中的 category: engineering / product / research，并调整受支持的简单相对链接。它是规则工具，无需模型密钥。更多说明见下载包 docs/user-guide.zh-CN.md。
