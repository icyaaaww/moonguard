# MoonGuard 月盾 1.0.0

公开发布的本地文件操作工作台，支持先预演、检查后执行和冲突感知恢复。

## 下载与使用

下载 `MoonGuard-1.0.0.zip`，完整解压。需要 Node.js 22 或以上。
Windows 双击 `Start-MoonGuard.cmd`；Linux/macOS 运行 `sh start-moonguard.sh`。
启动器自动选择空闲端口。打开页面后点击“打开资料目录”，用“新建操作”创建计划。
下载包含编译后的核心，无需 MoonBit 编译器；普通使用无需安装 npm 依赖。

`SHA256SUMS.txt` 提供压缩包校验值。Windows 可使用 `Get-FileHash .\MoonGuard-1.0.0.zip -Algorithm SHA256` 核对。

## 本版新增

- 页面打开真实资料目录，切换时作废旧计划并保留恢复记录。
- 表单创建移动、重命名、新建、修改、回收计划，无需编写 JSON。
- Windows 启动入口与跨平台脚本、自动空闲端口、参数校验和友好错误提示。
- 展示未参与处理的项目；新增普通用户使用手册。
- MCP 仍提供文件读取、提案与状态查询，执行留在本地工作台。

## 验证与范围

发布前执行 35 项 MoonBit 测试（JS / Wasm GC 各一轮）、26 项宿主测试、3 项 MCP 跨进程测试，以及 1 项覆盖页面表单与真实文件往返的 DOM 集成测试。远程 CI 分别检查 Linux 和 Windows，具体结果见此版本提交对应的 Actions。

1.0 面向小型 UTF-8 文本目录：最多 200 个文本文件、200 个操作。移动表单不会自动改写链接；规则归档器只支持受限的分类和 Markdown 链接格式。恢复日志不等于全盘备份。

macOS、真实大模型/OpenSeek 会话、规模化使用尚未验证；真实试用人数仍为 0。1.0 新增界面的真实浏览器验收本轮未完成：自动审批阻止了后台浏览器启动。API 和文件系统测试结果不替代页面验收。

## 升级与反馈

停止旧进程，将新版解压到新目录，重新打开原资料目录。保留 `.moonguard` 恢复日志；不需要迁移现有 schema 1 日志。
问题反馈：GitHub Issues。请提供版本、系统、虚构文件复现步骤；不要公开原始文档或恢复日志。
