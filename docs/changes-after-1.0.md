# 1.0 发布后的改进

以下改进位于 GitHub 主分支。下载源码即可使用；已发布的应用 v1.0.0 和 Mooncakes 0.1.0 保持原样。

## 文档分类识别

归档器只采用文件开头、由 `---` 闭合的简化 frontmatter。支持 UTF-8 BOM、CRLF，以及不带引号或单/双引号包裹的 `engineering`、`product`、`research`。未闭合、重复 category、其他分类或复杂 YAML 值不会触发移动。正文中的 category 不作为元数据。

验证：新增未闭合/重复分类拒绝移动、带 BOM/引号分类的内容保留与恢复测试；MoonBit JS 和 Wasm GC 各 37 项通过。

## 代码示例保护

链接改写现在记录代码围栏的字符种类和完整长度，只有相同字符、长度足够、后面只有空白的结束围栏才关闭代码块。支持最多三个前导空格；四空格或制表符开头的行保守地保留原文。较短围栏、错误字符、带尾部文字和未闭合围栏内的链接不会被改写。

这是简化 Markdown 支持，不是完整 CommonMark 解析器；引用式链接、编码 URL 等原有边界仍适用。验证覆盖长围栏、混用字符、CRLF、缩进与围栏后普通链接；MoonBit 两个目标各 39 项通过。

## 跨平台路径一致性

快照和计划统一检查各级目录的大小写，包括尚未创建的父目录和不可操作项。`Docs/a.md` 与 `docs/b.md` 不能在同一工作区混用；通过先回收 `a.md` 再创建 `A.md` 的操作组合也会在预演时拒绝，避免在大小写不敏感的文件系统上执行到一半才出错。应沿用已有目录的拼写。补充拦截 Windows 的 `COM¹`、`LPT²`、`COM³` 等保留设备名。

验证包括 MoonBit 快照、操作组合测试，以及真实文件系统的拒绝写入和合法路径执行/恢复测试。

## CLI 执行前检查与计划导出

新增 `check <workspace> <preview.json>`，只读核对计划与当前快照，以 JSON 报告问题；新增 `preview --output <file>`，将计划直接保存为 UTF-8，拒绝覆盖与工作区内输出。输入支持 UTF-8 BOM，错误的 operations 文件会明确报错，不再意外退回自动归档。`--help` 和退出码使脚本接入可判断成功、输入错误和检查失败。

验证：5 项跨进程 CLI 测试覆盖完整预演/检查/执行、过期与篡改计划、覆盖保护、目录链接绕入工作区、无效输入和非零退出码。

## 恢复前预演

工作台恢复按钮先显示逐文件内容预演，允许取消，有冲突时禁止确认。确认请求绑定事务、工作区及已审阅的快照；确认期间重新计算恢复计划，快照变化即拒绝。CLI 新增 `restore-preview`，HTTP 新增 `/api/restore-preview`。旧 CLI `restore` 和未传 reviewId 的 HTTP 恢复入口保持兼容，仍在执行前检查冲突。

预演也支持中断事务；文件已是原始内容但日志未完成时，允许确认完成恢复记录。新增测试验证预演不更改文件/日志、过期快照、人工修改冲突、错误预演编号与重复确认。DOM 测试覆盖取消、冲突、重新预演和最终确认。实际内置浏览器使用隔离示例完成了归档、恢复内容展开及确认恢复。

本次本地验证：MoonBit JS 与 Wasm GC 各 42 项，宿主/CLI/HTTP 38 项，MCP 3 项，UI DOM 1 项全部通过。全目标编译检查、生成接口/格式检查及 Mooncakes 包清单检查通过；公开 MoonBit API 无变化。远端 Linux/Windows 验证以 GitHub Actions 为准。
